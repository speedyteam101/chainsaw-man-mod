Installing

All four mods are built from source the same way:

  1. Put the mod's folder inside your tModLoader ModSources folder (on Windows, usually Documents/My Games/Terraria/tModLoader/ModSources). The folder name must match the mod: ChainsawManMod, DoorsMod, RobotJack or, for Shinobi, the ninjafight folder from its repository.
  2. In tModLoader open Workshop → Develop Mods and click Build + Reload next to the mod.

Each mod page has its own install notes. The DOORS and Shinobi mods were written without being compiled, so their first build may show errors that need fixing.
