Install

The mod is built from source inside tModLoader. You need Terraria with tModLoader 1.4.4, which is free on Steam.

Build the mod

  1. Launch tModLoader once

    This creates its ModSources folder:

    WindowsDocuments\My Games\Terraria\tModLoader\ModSources
    Linux~/.local/share/Terraria/tModLoader/ModSources
    macOS~/Library/Application Support/Terraria/tModLoader/ModSources

  2. Clone the repo as ChainsawManMod

    Inside ModSources. The folder name must match the mod name exactly.

    git clone https://github.com/speedyteam101/chainsaw-man-mod.git ChainsawManMod

  3. Build it

    In tModLoader, go to Workshop → Develop Mods → ChainsawManMod → Build + Reload.

  4. Enable the mod and play

    Start with the getting started items.

Troubleshooting

"Namespace and Folder name do not match. The top level namespace must match the folder name."

The folder inside ModSources has the wrong name. It must be exactly ChainsawManMod, with the same capitals. Rename it, then Build + Reload again.

Replacing the art

The Chainsaw Devil, Hero of Hell, Makima, Reze and Katana Man sprites are cleaned from supplied sprite sheets by tools/clean_sprite_sheet.py. Almost everything else is a simple placeholder generated by tools/generate_sprites.py. You can replace any PNG with your own art at the same size. The hybrid form sheets use 48 × 52 pixel cells, with one animation per row.

To make the transformation sprite bigger or smaller in game, change SpriteScale in Content/Players/ChainsawDevilDrawLayer.cs.
